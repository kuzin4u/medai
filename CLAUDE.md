# CLAUDE.md — правила работы в этом репозитории

## Что это
Пул материалов «ИИ в медицине» и рабочая модель «Концентрация и дыхание».
Всё — статические HTML-файлы без сборки: открываются файлом и работают офлайн.
Деплой: папка `site/` кладётся целиком на хостинг (например `lucklyrics.ru/medai/`).

## Правила
1. **Правки только после «да».** Сначала показать, что предлагается изменить, дождаться подтверждения, потом менять.
2. **Коммит делает Claude по команде.** `push` и Pull Request — всегда владелец.
3. **Ветка:** работа в `claude-setup`, слияние в `main` — владелец.
4. **Ничего не удалять** без явного указания: старые файлы и ссылки сохраняются.
5. **После любой правки HTML — `/verify`.** Без прохождения тестов правка не считается сделанной.

## Границы
- Не трогать `site/concentration-breathing-model.html` крупными переписываниями: это авторская модель, правки точечные, через `str_replace`.
- Не менять формат записи `cb-record-1` без записи в `docs/DECISIONS.md`.
- Не заявлять в текстах лечебных эффектов: продукт позиционируется как общее благополучие, см. `docs/SPEC-record.md`.
- Секреты в репозиторий не попадают. Ключей здесь нет и быть не должно.

## Как устроен код модели
Один файл, один тег `<script>`, без модулей. Блоки в конце файла добавлены слоями:
верхнее меню и настройки → подсказки → причины и вопросы → запись сессии.
Каждый слой самодостаточен и цепляется к существующим элементам по `id`.

## Очередь работ
Открытые задачи — `docs/BACKLOG.md`, в порядке З-1…З-10. Начинать с З-1: коды причин нужны всем остальным задачам.
Каждая постановка содержит «Готово, когда» — это и есть критерий приёмки.

## Проверка
`npm test` — прогон jsdom-тестов из `tests/`. Canvas и звук подменяются заглушками.

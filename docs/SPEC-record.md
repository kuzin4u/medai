# Запись сессии, хранение и выгрузка

## Версия формата
`cb-record-2` — с кодом причины (задача З-1, решение Р-8). Предыдущая — `cb-record-1`.
Старые записи при чтении получают `reasonCode` по строке; неизвестная строка — `R00` и `reasonUnknown: true`.
Менять только с записью в `DECISIONS.md`.

## Состав записи
| Группа | Поля | Происхождение |
|---|---|---|
| служебное | id, fmt, startedAt, tz, durationSec | — |
| stated | reason, reasonCode, reasonGroup, pre{ctx, area, quality, level}, post{level, change, done, hinder}, note, postSkipped | заявлено человеком |
| set | organ, params{t-in, t-h1, t-out, t-h2, s-h2, c-freq, c-force, heart-rate}, preset | задано настройкой |
| measured | device, samples, ряды пульса, RR-интервалов, SpO₂ | измерено прибором |
| marked | события: контакт, Б1, Б2, отклик; ряд реакции | отмечено во время сессии |
| derived | длительности задержек, время до контакта, ВСР, изменение показателей | вычислено моделью |

Состояния ответа: **дан**, **пропущен** (`__skipped`), **не задавался** (поля нет).

## Хранилище (IndexedDB `cb_records`)
- `index` — строка на сессию для списков и сводок (~200 байт), с `reasonCode`.
- `sessions` — полная запись без сырья (<1 КБ).
- `series` — сырые ряды (~10 КБ на 15 минут). **Пока не заполняется — задача З-2.**

## Сроки
| Что | Срок | Дальше |
|---|---|---|
| сырьё | 3 года | свернуть в производные, только после успешного архива |
| записи сессий | 10 лет | — |
| указатель | бессрочно | — |

## Сводка (не реализована — задача З-4)
Период по умолчанию 90 дней, переключение на 30 и на всё время.
Строка на пару «причина + область»: число сессий, среднее до, среднее после,
разница до/после (помогает ли в моменте), тенденция значения до (меняется ли фон).
Порог: при менее чем 5 сессиях средние не показывать.
Наверх выносятся три сигнала: рост значения до, появление отметок «усилилась», обрыв практики.

## Выгрузка (не реализована — задача З-5)
- **Врачу-человеку** — одна-две страницы: шапка с оговоркой о происхождении данных, сигналы, строки по областям, регулярность, последние заметки дословно.
- **ИИ-ассистенту врача** — структурированный файл с метками происхождения и словарём полей в самом файле.
- **ИИ пациента** — то же плюс история запросов.
Выгружается сводка. Журнал и сырьё — отдельным действием и отдельным согласием.
Перед каждой выгрузкой человек видит свёрнутый список: период, состав, получатель.

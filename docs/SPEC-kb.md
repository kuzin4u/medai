# Пул базы знаний — правила материала

## Состав
`index.html` титул · `00` российский сегмент · `01` зарубежный · `02` параллели с платежами ·
`03` инструменты практики · `04` процессная модель · `05` трек освоения · `06` уровень участия.

## Происхождение позиций
- **документ** — нормативный акт, стандарт, официальный источник; можно предъявлять заказчику.
- **наблюдение** — новость, рыночные данные, заявление участника рынка; проверять актуальность.
- **вывод** — наша реконструкция и постановка, не факт.
- **проект** — документ в разработке.

## Правила
1. Реестры документов упорядочены по юридической силе; дочерние акты — с отступом под родительским.
2. В глоссариях сокращения раскрываются полностью, у каждого термина ссылка на источник.
3. Подсказки и тексты используют названия элементов модели дословно.
4. Страницы самодостаточны: ни сборки, ни общих файлов, ссылки относительные.

## Размещение
Страница `02` ссылается на пул `agentic/` по адресам `../agentic/*.html` (восемь ссылок и ссылки, собираемые скриптом).
Условие: на хостинге папка `agentic/` лежит рядом с `medai/`. В репозитории её нет, тест ссылки `../` не проверяет.

## Что устаревает быстрее всего
Разделы «Рынок и игроки», реестры документов, зарубежная регуляторика.

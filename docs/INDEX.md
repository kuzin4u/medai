# Указатель документов

| Документ | О чём |
|---|---|
| `STATUS.md` | текущее состояние, что сделано, что открыто, расхождения |
| `DECISIONS.md` | журнал решений: что решили, почему, что меняет |
| `BACKLOG.md` | постановки открытых задач З-1…З-10 в порядке выполнения |
| `SPEC-model.md` | модель «Концентрация и дыхание»: экраны, меню, дерево сценариев |
| `SPEC-record.md` | формат записи сессии, хранение, сроки, выгрузка |
| `SPEC-kb.md` | пул базы знаний: состав страниц и правила материала |

## Где что лежит в коде
- `site/concentration-breathing-model.html` — модель, один файл, один `<script>`, слои в конце файла.
- `site/0*.html` — страницы базы знаний, каждая самодостаточна.
- `tests/smoke.js` — прогон всех страниц и сценария сессии.
